# ETF 动能雷达

个人使用的本地 ETF 动能轮动工具。它以文章中的“动量形成质量”为核心，将传统收益动量改造成适合 ETF 的多因子模型。

## 启动

```bash
npm start
```

浏览器打开 <http://127.0.0.1:8787>。

## 当前模型

- 20/60/120 日收益动量，均跳过最近 5 个交易日
- 60 日路径效率：净位移 / 每日波动路程
- MA20、MA60 趋势确认
- 60 日最大回撤与 20 日波动惩罚
- 20 日平均成交额过滤
- 沪深300、科创50、创业板、北证50联合判断进攻、均衡、防守状态
- 趋势生命周期：形成、加速、分歧、衰竭、反转
- 每只ETF提供操作倾向、确认触发、失效条件与三情景模板
- 自动生成按市场状态约束的ETF组合与现金仓位
- 保存当前采用组合；目标组合变化时显示新增、移出和调仓提醒

综合排名并非只看涨幅：原始动能分完成横截面选强，生命周期模型再对已经衰竭或反转的标的降权。

因子采用横截面百分位合成，因此分数表示当前候选池内的相对强弱，不是预期收益率。

## 数据说明

默认适配器读取东方财富公开行情接口：实时快照每 5 秒刷新，日线因子缓存 15 分钟。日线主源失败时自动切换腾讯财经K线，避免因单一公开接口中断导致扫描结果为空。公开接口可能延迟、限流或变更，仅适用于个人研究。正式实盘使用前，应替换为持牌券商或付费行情接口。
