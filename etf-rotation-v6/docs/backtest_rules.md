# 回测规则

1. 每个交易日的因子只读取该日及以前的价格。
2. 当前工程版本仅有收盘价，因此采用明确的收盘成交模型：
   `T` 日收盘产生信号 → `T+1` 日收盘成交 → 新仓位影响
   `T+1` 日收盘至 `T+2` 日收盘的收益。
3. `T` 日信号不得影响 `T` 日收盘至 `T+1` 日收盘的收益；最后一个交易日形成的
   信号因缺少下一交易日，不得生成成交事件。
4. 仅在配置的调仓间隔形成新目标，调仓之间持仓延续。
5. 非调仓日的实际权重随各资产价格自然漂移，不得自动恢复为原始目标权重。
   未投资部分作为现金，当前现金收益率按零处理；防守和均衡仓位不得被重新归一化为
   100% 风险资产。
6. 成交前权重是价格变化后的实际漂移权重；换手率按漂移权重与新目标权重的资产权重
   变化绝对值之和计算，不包含额外的现金一边，也不除以二。
7. 每次策略调仓必须记录信号日期、成交日期、成交前漂移权重、成交后目标权重、标的和
   成交价格类型；只有权重实际变化的资产才写入成交事件。
8. 单标的权重不得超过 `max_position`。
9. 市场状态控制组合总风险暴露，未使用权重为现金。
10. 换手率乘以单边手续费，在成交日收盘从组合收益中扣除；当前尚未实现滑点。
11. 净值从高点回撤达到阈值后清仓并进入固定冷却期。
12. 缺失收益按零处理仅用于样例；正式数据应先完成上市期和停牌规则。
13. 未来获得可靠开盘价数据后，可以另行实现 `T+1` 开盘成交模型；在此之前不得
    用收盘价数据伪造开盘成交。

必须通过 `test_no_lookahead.py`，任何使用未来价格修正历史信号的实现均视为失败。
