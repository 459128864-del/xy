用于实盘判断或宣称策略有效。

## 数据规则

- 只使用双方均存在的交易日。
- 不对缺失基准日期做前向填充。
- 比较模块不向策略模块回写任何信息。
- 原始行情和生成的逐日比较表保留在 Git 忽略目录或临时目录。
