# 数据字典

输入采用 UTF-8 CSV 长表，每行代表一个 ETF 在一个交易日的收盘观察。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `date` | date | 是 | 交易日期，可被 pandas 解析 |
| `symbol` | string | 是 | ETF 唯一代码 |
| `close` | float | 是 | 前复权或后复权收盘价，必须为正 |

同一 `date`、`symbol` 组合应唯一。真实研究需保证复权方法一致，并保留已退市、
合并或更名标的以控制幸存者偏差。

每只 ETF 的上市历史按其自身按日期排序后的观察数独立计算。观察数小于
`strategy.minimum_history`，或任何必需因子尚未形成时，该标的不得参与当日评分和
选券。该规则不使用未来记录补足过去历史。

回测输出净值表字段：

| 字段 | 说明 |
|---|---|
| `date` | 交易日期 |
| `return` | 扣除交易成本后的组合日收益 |
| `equity` | 累计净值 |
| `turnover` | 当日目标权重绝对变化之和 |
