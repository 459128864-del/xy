# 双向日内 T 雷达

独立于 V6 的研究、提醒与逐 bar 回放模块；**无券商连接、无自动下单**。首次启动直接进入显著标识的演示模式。用户设置只写入被 Git 忽略的 `data/intraday-t-config.json`。

## 启动与测试

```bash
npm run intraday-t       # http://127.0.0.1:8790
npm run test:intraday-t
```

## 口径

- 5 分钟收盘 bar 才进入计算；摆动点等右侧 `pivot_right` 根收盘后确认。15 分钟过滤器只能聚合完成的三个 5 分钟 bar。回放器每次只暴露游标以前的数据。
- VWAP 当前采用典型价 `(H+L+C)/3 × volume / Σvolume`，因为公共源成交额和成交量单位尚未统一验证；绝不与成交额口径混用。
- ATR 使用 Wilder RMA，MACD 为 EMA(12/26/9) 且 DIF/HIST 归一化为 bps。费率、滑点、最小 RR、摆动参数和时段均来自示例/本地配置。
- 公共行情适配的复权、停牌、新上市、涨跌停精确口径及备用源单位均为**待确认**；未验证前安全失败，不产生 A 级提醒。本次交付用演示数据，未伪装成实时行情。
- 正 T 先买增量、退出时提示卖等量隔夜可用旧仓；倒 T 先卖隔夜可用旧仓、退出时提示买回。数量缺字段时只展示形态并明确不可执行。

## 已知限制

当前版本完整提供隔离服务、配置安全边界、指标/背离/成本/数量/状态机的可测试核心以及零构建验收页面。东方财富实时适配、自动缓存、桌面通知/Webhook、完整 K 线交互及交易日历仍待后续在数据口径确认后接入；因此演示页面不会产生实时 A 级信号。

本模块不是 V6 结果，未修改 `etf-rotation-v6` 策略、参数、回测或基准，也未提交真实持仓、现金或成本价。
